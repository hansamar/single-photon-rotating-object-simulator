# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-05-30

### Added

- Initial public release of the browser-based rotating-object single-photon
  LiDAR/ToF simulator.
- Angular interface for image upload, parameter control, 3D scene inspection,
  visualization, and raw `.bin` export.
- Photon-level synthetic data generation with Poisson-distributed signal events
  and configurable background noise.
- Open-source license, contribution guidance, and project roadmap.
