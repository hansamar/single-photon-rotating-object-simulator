# Roadmap

This roadmap describes the current direction of the project. It is intentionally
small and may evolve as the simulator gains validation examples and users.

## Validation and Reproducibility

- Document the exported `.bin` layout and add Python and MATLAB loading examples.
- Add deterministic random seeds for reproducible simulation runs.
- Add reference scenarios for checking timing, noise, and geometric projection.
- Add automated checks for the simulation parameter boundaries.

## Research Usability

- Add small example blade images and example parameter presets.
- Document the assumptions and limitations of the SPAD and background-noise
  model.
- Add a lightweight browser demo deployment.

## Maintenance

- Add continuous integration for production builds.
- Add issue and pull request templates as the contributor workflow grows.
- Publish versioned releases with changelog entries.
